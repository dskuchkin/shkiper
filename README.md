# SHKIPER VPN

Лендинг SHKIPER VPN — статический сайт (HTML / CSS / JS).

## Структура
- `index.html` — разметка страницы
- `styles.css` — стили (фирменная палитра: королевский синий)
- `script.js` — интерактив и анимации
- `media/` — изображения (маскот-пингвин, скриншот приложения)

## Запуск
Открыть `index.html` в браузере или поднять статический сервер:

```bash
python3 -m http.server 8000
```
